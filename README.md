# Tokri Expense Tracker app

When going out to buy groceries we need a list of items to buy, usually a paper list which is easy to keep and easy to lose also checking all items brought ,putting its price and cutting all items skipped is difficult in public spaces.
But we always have a phone in pocket and we definitely take it out to scam QR code ,why not have ur list of item in ur phone itself with some features which make it effortless easy.

THATS WHERE TOKRI CAME IN ,With tokri
- you will add items before going to market
- set quantity (5kg ,2L ,4packets)
. Tokri shows the items you need to purchase ,the quantity u need to purchase it for and a empty space for u to insert the price of item of that particular quantity.
. Tokri saves the price of item and compare it when u buy the same item again ,while inserting item name u will get autofill.
. Tokri save ur time by letting u get item set brought by one swipe to right ,item skipped (not available in market) by one swipe to left
. Tokri shows the price u brought the item with last time so that u can bargain or compare it! (In later version we will use all input of same item to set a common price by people) [such as : potato price is set as 30 by 10 people and 20 by 5 people then tokri shows lowest price and average price]
